# gpb-launcher

Google Play Games(베타) 게임을 원하는 화면비로 실행하는 런처입니다.

## 원리

구플베는 게임을 켜는 순간, 게임 창이 뜨는 모니터의 비율로 게임 창 비율을 정하고, 그 뒤에 해상도가 바뀌어도 비율을 유지합니다. 그래서 잠깐 해상도를 바꿔서 게임을 켜고 바로 되돌립니다.

```
3840×2160  →  3840×1728 (20:9)  →  게임 창 뜸  →  3840×2160
```

1. 해상도를 바꿀 모니터를 찾습니다. 주 모니터를 먼저 확인하고, 지원하는 해상도가 없으면 다른 모니터를 차례로 확인해서 처음 만나는, 그 해상도를 지원하는 모니터를 씁니다. 이어서 그 모니터의 지금 해상도와 주사율을 기억합니다.
2. 바로가기에 적힌 해상도와 주사율로 바꿉니다. 설정에 저장하지 않는 임시 변경이라, 프로그램이 죽어도 재부팅하면 원래대로 돌아옵니다.
3. `C:\Program Files\Google\Play Games\Bootstrapper.exe`에 게임 링크를 넘겨 게임을 실행합니다.
4. 게임 창(`crosvm.exe`)이 뜨면 구플베 창(`client.exe`의 "Google Play Games")을 닫고, 1번에서 기억한 해상도로 바로 되돌립니다. 오류가 나거나 시간이 초과돼도 항상 되돌립니다.

## 사용법

### 준비

- NVIDIA 앱 같은 그래픽 설정에서 원하는 해상도를 사용자 지정 해상도로 만들어 둡니다. 주사율을 생략해서 쓸 거라면 그 모니터의 지금 주사율로 만들어야 합니다.
- Google Play Games(베타)에서 게임을 설치합니다. 설치하면 시작 메뉴의 `Google Play Games` 폴더에 게임 바로가기가 생기고, `build.ps1`이 그 바로가기에서 게임을 찾습니다.

### 빌드

`build.ps1`을 우클릭해서 **PowerShell에서 실행**을 누릅니다.

1. 게임을 고릅니다. 시작 메뉴에 게임 바로가기가 하나뿐이면 자동으로 정해집니다.
2. `게임`과 `만들 파일`을 확인하고 `Y`를 누르면 `<게임 이름>.exe`가 만들어집니다. 게임 아이콘과 게임 패키지 이름이 exe 안에 들어갑니다.
3. 빌드가 끝나면 만들어진 exe를 실행해서 바로가기를 만듭니다.

빌드는 한 번만 하면 됩니다. 게임 정보가 exe 안에 들어 있어, 같은 exe를 다시 실행하면 언제든 다른 해상도의 바로가기를 더 만들 수 있습니다.

빌드에는 Windows에 기본으로 들어 있는 C# 컴파일러(.NET Framework 4)를 쓰므로 따로 설치할 것은 없습니다.

### 바로가기 만들기

`<게임 이름>.exe`를 직접 실행하면 바로가기 만들기 창이 뜹니다.

1. 주 모니터가 지원하는 모든 해상도가 `3840x2160  (16:9)`처럼 나옵니다. Windows 디스플레이 설정의 해상도 목록과 같은 순서(가로, 세로가 큰 순서)로 나오고, 지금 해상도에는 `현재`가 붙습니다.
2. 가로, 세로, 주사율 칸은 지금 해상도로 채워져 있습니다. 목록에서 해상도를 고르면 그 해상도의 가로, 세로가 칸에 들어가고, 주사율은 그 모니터의 지금 주사율이 그 해상도에 있으면 그 값, 없으면 그 해상도의 가장 높은 주사율이 들어갑니다.
3. 목록을 고른 뒤에도 가로, 세로, 주사율은 직접 고칠 수 있습니다. 주사율을 비우면 그 모니터의 지금 주사율(없으면 가장 높은 주사율)을 씁니다.
4. `바로가기 만들기`를 누르면 exe 옆에 `<게임 이름> (가로x세로@주사율)` 바로가기가 생깁니다.

같은 게임의 다른 해상도 바로가기를 더 만들려면 exe를 다시 실행해서 고르면 됩니다. 이후에는 `build.ps1`이 필요 없습니다.

바탕화면이나 시작 화면에 두려면 이 바로가기를 복사하거나 고정하세요.

### 실행

게임을 완전히 끈 상태에서 바로가기를 실행합니다. 게임이 이미 켜져 있으면 비율이 바뀌지 않습니다.

구플베는 게임 창을 마지막에 있던 모니터에 띄웁니다. 해상도를 바꾼 모니터가 아닌 곳에 게임 창을 마지막으로 두었다면, 게임 창을 원하는 모니터로 한 번 옮겨 두고 게임을 끈 뒤 실행하세요. 게임 창이 다른 모니터에 뜨면 런처가 해상도를 되돌린 뒤 알려 줍니다.

해상도가 바뀐 채 남았다면 재부팅하거나 디스플레이 설정에서 원래 해상도를 고르면 됩니다.

### 옵션

바로가기 속성의 대상 끝에 붙여서 쓸 수 있습니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--game` | exe에 저장된 게임 | 실행할 게임의 패키지 이름 (예: `com.epidgames.trickcalrevive`). `<게임 이름>.exe`에 들어 있고, 바로가기를 만들 때 자동으로 붙습니다 |
| `<가로>x<세로>[@주사율]` | 현재 해상도 | 게임을 실행할 해상도 (예: `3840x1728@144`). `@주사율`을 빼면 현재 주사율을 쓰고, 이 값을 빼면 해상도를 바꾸지 않고 게임만 실행합니다. `--width`/`--height`/`--hz`로도 지정할 수 있습니다 |
| `--settle` | 0 | 게임 창이 뜬 뒤 되돌리기 전에 더 기다릴 초 |
| `--timeout` | 90 | 게임 창을 기다리는 최대 초 |
